# Devlog #36 (fcc4f2f):

I made the first gameplay change in a while, and also changed the theming a bit more.

## The gameplay changes
I noticed that the game was getting a bit... repetitive, so I changed the bot to have an element of randomness when there are multiple spots that provide similar advantage. This took me a long time, because my code is spaghetti, and also because random in JavaScript is so much better than in C++

## The visual changes
I changed the theming of the game because I didn't think the discord-esque style looked very good. Now, it's changed to match the "Arch" theme on Monkeytype. I also changed the font to Roboto Mono since that's what my configuration of Monkeytype uses.
